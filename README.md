# Django-проект интернет-магазина

## В проекте реализовано приложение catalog:
* в модуле views приложения реализованы функции рендеринга домашней страницы и страницы контактов
* в модуле urls приложения прописаны пути до выше указанных страниц
* в папке templates заданы шаблоны в формате html для отображения выше указанных страниц

## Установка:
1. Клонируйте репозиторий:
```git clone git@github.com:elenasyurtukova/DjangoProjectShop.git```

2. Установите библиотеки из pyproject.toml:
```poetry install```
